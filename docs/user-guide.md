# Uživatelská příručka

## Rychlý začátek

1. Otevřete [HAREC do kapsy](https://rudi1984.github.io/Radioamat-rsk-zkou-ky-/).
2. Klepněte na **Spustit 10 otázek** pro okamžité procvičování.
3. Vyberte odpověď A, B nebo C. Aplikace ihned označí správnou volbu a případně vyznačí chybu.
4. Přesuňte se na další otázku. Na konci se zobrazí výsledek a volba opakovat chyby z této série.

## Režimy

- **Vlastní test:** zvolte A/B/C, kartičky nebo opakování chyb, oblast, podtéma a délku série.
- **Učení:** odpověď se nejprve nezobrazí. Po volbě **Ukázat odpověď** označte **Umím** / **Neumím**. Toto se počítá do statistik jako sebehodnocení.
- **Moje chyby:** opakuje otázky označené jako chybné v dřívějším procvičování. Po správné odpovědi se otázka vyřadí z aktuálního seznamu chyb.
- **Přeskočit:** otázka se nepovažuje za správnou ani chybnou; ve výsledku se započítá zvlášť jako přeskočená.

## Proč se počty nezobrazují jako unikátně naučené otázky?

Počítadlo zobrazuje **počet vyhodnocených odpovědí**, včetně opakování stejné otázky. Nenazýváme ho počtem různých naučených otázek.

## Instalace na Android

V Chromu použijte nabídku **Nainstalovat aplikaci** nebo **Přidat na plochu**. Dostupná varianta závisí na prohlížeči a systému. Na plochu získáte ikonu a u podporované PWA se otevře samostatné okno.

## Offline režim

Při prvním spuštění nechte aplikaci načíst online. Pro ověření vypněte datové připojení a Wi‑Fi; aplikace má dál zobrazit otázky. První spuštění nově nasazené verze online může být nutné pro přednačtení souborů.

## Aktualizace

Po nahrání souborů na GitHub Pages a načtení nové verze aplikace může přijít oznámení **Aktualizovat**. Potvrďte aktualizaci ideálně mimo rozpracovaný test. Pokud se aktualizace neukáže, zkuste aplikaci zavřít a znovu otevřít online. Nemažte data prohlížeče kvůli aktualizaci, protože byste mohli přijít o statistiky.

## Pokrok a záloha

V sekci **Více** je počet vyhodnocených a správných odpovědí, seznam chyb a tlačítko **Stáhnout zálohu výsledků**. Export obsahuje JSON se statistikami. **Obnova ze souboru zatím není implementovaná**; export slouží jako archiv a pro případnou budoucí obnovu.

Pokrok se automaticky nepřenáší mezi telefonem a počítačem, ani mezi izolovanými profily prohlížeče.

## Hlášení chyby

V testové otázce použijte odkaz **Nahlásit problém s otázkou**. Otevře předvyplněný GitHub Issue s kódem a textem otázky. Hlášení zatím vyžaduje GitHub účet.
